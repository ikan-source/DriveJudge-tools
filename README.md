# Drive Judge — カーシェア vs レンタカー

目的地までの実走距離から、**カーシェア（三井・タイムズ・オリックス）**と**レンタカー（トヨタ・ニッポン・オリックス・格安系）**を横断比較し、距離料金・ガソリン代・高速代・AA割り勘まで込みで最安を判定するツール。単一の静的サイトなので GitHub Pages にそのまま置けて、PWA としてスマホにインストールもできる。

## できること（v3）

- **Google Maps 実走距離**：出発地〜目的地の距離・所要時間を自動測定。アドレス補完つき
- **ルート地図表示**：ダークテーマの地図に経路と各停車地点を描画
- **複数の立ち寄り先**：出発地 → 各スポット → 出発地に戻る周回ルート（最大8地点）。距離は全区間の合計
- **横断ランキング**：カーシェア3社・レンタカー4系統を一覧比較。各社の距離料金モデルの違いを反映
  - 三井：6時間以内なら距離料金0円、超えると全km課金
  - タイムズ：20km超過分のみ課金
  - オリックス：全km課金
- **代表車種の表示**：各社・各車格の代表的な車種（例：三井ミドル＝CX-5/RAV4/ハリアー…）
- **逆引きモード**：制限時間・人均予算から、早稲田起点で行ける範囲を提案
- 車格（ベーシック＝コンパクト / ミドル＝SUV級）の切替・夜間パック・AA割り勘・高速代の自動概算
- 各社の料金パラメータを編集 → 端末内に保存され、以降は自分の実勢で計算

## GitHub Pages へのデプロイ

1. このフォルダ（`index.html` / `manifest.json` / `sw.js` / `icon.svg` / `README.md`）をリポジトリにそのまま push（5ファイルは**リポジトリ直下**に置く。フォルダごと入れない）
2. リポジトリの **Settings → Pages** で、Branch を `main`（フォルダは `/(root)`）に設定して保存
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
4. スマホでそのURLを開き、Safari/Chrome の「ホーム画面に追加」で PWA としてインストール可

> 更新時は変更したファイル（多くは `index.html` / `sw.js`）だけを上書きアップロードすればよい。`sw.js` の `CACHE` バージョンを変えると古いキャッシュが破棄され、新版が確実に反映される。

## Google Maps API キーの取得

自動測距・地図を使う場合のみ必要（未設定なら「手入力」で距離を直接入れてもOK）。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. **APIとサービス → ライブラリ**で以下を有効化
   - **Maps JavaScript API**（地図表示）
   - **Places API**（住所オートコンプリート）
   - **Directions API**（ルート・距離計算）
3. **認証情報 → APIキーを作成**
4. 作成したキーの**制限**を必ず設定（重要）：
   - アプリケーションの制限：**HTTP リファラー（ウェブサイト）**
   - 許可リストに自分の Pages ドメインを追加：`https://<ユーザー名>.github.io/*`
   - API の制限：上の3つのAPIに限定
5. 課金（Billing）を有効化（下記コスト参照）
6. アプリ画面にキーを貼って「有効化」。キーは**端末のローカルストレージにのみ保存**され、サーバーには送らない

> クライアントサイドにキーが出るのは Maps JS の通常仕様。**必ずリファラー制限をかけること**で第三者の悪用を防ぐ。

## コストと使いすぎ防止（重要）

2025年3月以降、Google Maps Platform は「月$200クレジット」を廃止し、**SKUごとの月間無料枠**に変更。Essentials カテゴリ（動的地図の表示・Directions・Autocomplete などが該当）は**各SKU 月10,000回まで無料**。個人が手動で1か月に数十回測距する程度なら、まず無料枠内（**実質 ¥0**）に収まる。超過時は動的地図でおよそ $7 / 1,000回。
（最新条件は https://mapsplatform.google.com/pricing/ で確認のこと）

### 安心のための2段構え

「無料枠の◯%」は**回数**の話、Budget アラートは**金額（¥）**の話で、別物。無料枠内だと金額は¥0なので、金額予算では「無料枠80%」は検知できない。回数を見張りたいなら Quota（B）を使う。両方やると万全。

**A. 金額予算アラート（万一の課金に対する保険／最優先）**
1. Console → **お支払い（Billing）→ 予算とアラート → 予算を作成**
2. 対象：このプロジェクト
3. 予算額：**¥100** など極小額（正常時は¥0なので、課金が始まったら即わかる保険）
4. しきい値で **50% / 90%** に「メールで通知」をオン → 保存
→ もし設定ミスや不正利用で課金が始まっても、¥50到達でメールが届く。

**B. 回数の上限（“無料枠の◯%で止めたい/知りたい”に対応）**
1. Console → **APIとサービス → 各API（Maps JavaScript / Places / Directions）→ 割り当て（Quotas）**
2. 各APIに**1日あたりの上限**を設定（例：各300回/日）
→ 個人利用では到達しないが、暴走や不正時に**上限で自動停止**するため、課金そのものを未然に防げる。回数監視・80%通知に最も近いのはこの方法。

個人の手動利用なら **A だけでも十分**。神経質に回数も管理したいなら B も設定。

## 料金データについて

各社に公開APIは無いため、料金は**公表料金をもとにした編集可能なモデル値**（2025年末〜2026年改定後の標準会員・標準シーズン目安）。エリア・季節・キャンペーンで変動する。アプリ内 ⚙︎ から実際の予約画面の数字に上書きすると保存され、以降そのまま使われる。代表車種は各社公式の車種ページに基づく代表例（実際の配車は station により異なる）。

出どころ：各社公式の料金・車種ページ（三井のカーシェアーズ／タイムズカー／オリックスカーシェア／トヨタ・ニッポン・オリックスレンタカー）および公開比較情報。

## カスタマイズの勘所（index.html 1ファイル完結）

- `DEFAULTS` … 全社・全クラスの既定料金
- `MODELS` … 各社・各車格の代表車種リスト
- `DEST` … 逆引きモードの目的地（早稲田起点の往復km・運転h・高速代の目安）
- `csDist()` … カーシェアの距離料金モデル（`mitsui6h` / `times20` / `all`）
- `rcCost()` … レンタカーの基本料金・CDW・燃料計算
- `computeRoute()` … 複数地点の周回ルート計算（Directions）

## 制限

- 高速料金は Google Directions が日本の料金を返さないため、距離からの概算（編集可）
- カーシェアの時間料金は「6h/12h/24hパックの段階」で近似。実際は端数を10〜15分課金と組み合わせて最安が自動適用されるため、境界付近は数百円ずれることがある
- 立ち寄り先は最大8地点（Directions の標準枠内）
- station ごとの実在庫・空車は公開APIが無いため非対応（各社アプリへ）
