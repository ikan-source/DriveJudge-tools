# Drive Judge — カーシェア vs レンタカー

目的地までの実走距離から、**カーシェア（三井・タイムズ・オリックス）**と**レンタカー（トヨタ・ニッポン・オリックス・格安系）**を横断比較し、距離料金・ガソリン代・高速代・AA割り勘まで込みで最安を判定するツール。単一の静的サイトなので GitHub Pages にそのまま置けて、PWA としてスマホにインストールもできる。

## できること

- Google Maps で出発地〜目的地の**実走距離・所要時間を自動測定**（往復で計算）
- カーシェア3社・レンタカー4系統を**一覧ランキング**。各社の距離料金モデルの違いを正しく反映
  - 三井：6時間以内なら距離料金0円、超えると全km課金
  - タイムズ：20km超過分のみ課金
  - オリックス：全km課金
- 車格（ベーシック＝コンパクト / ミドル＝SUV級）の切替
- 夜間パック・人数割り勘（AA）・高速代の自動概算
- 各社の料金パラメータを編集 → 端末内に保存され、以降は自分の実勢で計算

## GitHub Pages へのデプロイ

1. このフォルダ（`index.html` / `manifest.json` / `sw.js` / `icon.svg`）をリポジトリにそのまま push
2. リポジトリの **Settings → Pages** で、Branch を `main`（フォルダは `/root`）に設定して保存
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
4. スマホでそのURLを開き、Safari/Chrome の「ホーム画面に追加」で PWA としてインストール可

> サブフォルダ配信でも動くようパスはすべて相対（`./`）にしてある。

## Google Maps API キーの取得

自動測距を使う場合のみ必要（未設定なら「手入力に切替」で距離を直接入れてもOK）。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. **APIとサービス → ライブラリ**で以下を有効化
   - **Maps JavaScript API**
   - **Places API**
   - **Directions API**
3. **認証情報 → APIキーを作成**
4. 作成したキーの**制限**を必ず設定（重要）：
   - アプリケーションの制限：**HTTP リファラー**
   - 許可リストに自分の Pages ドメインを追加：`https://<ユーザー名>.github.io/*`
   - API の制限：上の3つのAPIに限定
5. 課金（Billing）を有効化。Maps Platform には月ごとの無料利用枠があるが、条件は変わるので[最新の料金](https://mapsplatform.google.com/pricing/)を確認のこと。個人の軽い利用なら通常は無料枠内に収まる
6. アプリ画面の入力欄にキーを貼って「有効化」。キーは**端末のローカルストレージにのみ保存**され、サーバーには送らない

> クライアントサイドにキーが出るのは Maps JS の通常仕様。**必ずリファラー制限をかけること**で第三者の悪用を防ぐ。

## 料金データについて

各社に公開APIは無いため、料金は**公表料金をもとにした編集可能なモデル値**（2025年末〜2026年改定後の標準会員・標準シーズン目安）。エリア・季節・キャンペーンで変動する。アプリ内の ⚙︎ から実際の予約画面の数字に上書きすると保存され、以降そのまま使われる。

出どころ：各社公式の料金ページ（三井のカーシェアーズ／タイムズカー／オリックスカーシェア／トヨタ・ニッポン・オリックスレンタカー）および公開比較情報。

## カスタマイズの勘所（コードは index.html の1ファイル完結）

- `DEFAULTS` … 全社・全クラスの既定料金。ここを直すと初期値が変わる
- `csDist()` … カーシェアの距離料金モデル（`mitsui6h` / `times20` / `all`）
- `rcCost()` … レンタカーの基本料金・CDW・燃料計算
- `DEST` 的な固定プリセットは v2 では廃し、Maps 実測 or 手入力に統一
- 反査モード（予算/時間内で行ける範囲）や行程の保存は未実装。追加しやすい構造にしてある

## 制限

- 高速料金は Google Directions が日本の料金を返さないため、距離からの概算（編集可）
- カーシェアの時間料金は「6h/12h/24hパックの段階」で近似。実際は端数を10〜15分課金と組み合わせて最安が自動適用されるため、境界付近は数百円ずれることがある
